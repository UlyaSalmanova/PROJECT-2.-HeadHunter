# Анализ рынка вакансий Data Science (hh.ru)

## 📌 О проекте
Проект выполнен в рамках учебного курса по анализу данных.  
Цель - исследовать рынок вакансий в сфере Data Science (и смежных), выявить ключевые тренды по зарплатам, востребованным навыкам, географии и форматам занятости.

## 📊 Данные
- **Источник:** Учебная база данных SkillFactory (собранные вакансии с hh.ru)
- **Объём:** 49 197 вакансий, 23 501 работодатель, 1 362 региона, 294 сферы деятельности

## 🔍 Ключевые задачи
1. Предварительный анализ структуры данных (распределение по регионам, сферам, работодателям)
2. Анализ требований к соискателям (опыт, ключевые навыки, формат работы)
3. Исследование зарплат: зависимость от опыта, региона, навыков
4. Детальный фокус на Data Science-вакансии

## 🛠 Используемые технологии
- **SQL** (PostgreSQL) - все запросы к базе
- **Python**:
  - `pandas` - обработка данных
  - `matplotlib`, `seaborn` - визуализация
  - `psycopg2` - подключение к БД
- **Jupyter Notebook** - среда выполнения
- **GitHub** - хранение проекта

## 📈 Основные выводы (кратко)
- **Рынок гиперконцентрирован:** Москва + СПб => 17% всех вакансий. 36% работодателей не указали сферу деятельности.
- **Удалёнка:** 18% в DS-сегменте.
- **Зарплаты DS:** Junior (75k) => Middle (140k) => Senior (243k). Рост 2-3 года даёт +87%.
- **Навыки:** Python - в 20% DS-вакансий, SQL - в 13%. Средний стек - 6-7 технологий.
- **Джуниорам сложно:** всего 2.9% от DS-вакансий.
